# Frontend

## Tecnologías usadas
- Angular v21
- scss

## Instalar Angular
> Version especifica
```bash
npx -p @angular/cli@17 ng new [nameProject]
```
> Ultima version 
```bash
npx @angular/cli@latest new [nameProject]
```

> Verificar version instalado
```bash
npx ng version
```

## Ejecución del servidor
```bash
npx ng serve
```
